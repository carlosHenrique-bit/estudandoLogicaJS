# Estudando Lógica com JavaScript

Repositório de estudos dedicado à prática de lógica de programação com JavaScript. Reúne exercícios introdutórios e um jogo de adivinhação de números desenvolvido para aplicar os conceitos aprendidos.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Conteúdo

- Variáveis e tipos de dados.
- Operadores e estruturas condicionais.
- Laços de repetição com `while`.
- Arrays e números aleatórios.
- Entrada e saída de dados com `prompt()` e `alert()`.
- Exercícios organizados na pasta `Desafios/`.

## Jogo do número secreto

O arquivo `index.html` executa um jogo em que o navegador sorteia um número entre 1 e 100. O jogador faz tentativas e recebe dicas para descobrir o número secreto. Ao acertar, o jogo informa a quantidade de tentativas.

## Como executar

1. Baixe ou clone o repositório.
2. Abra `index.html` em um navegador.
3. Siga as instruções exibidas nas caixas de diálogo.

Os exercícios da pasta `Desafios/` são arquivos de estudo independentes; alguns dependem de elementos HTML ou de interação pelo navegador.

## Sobre o projeto

Este repositório registra uma etapa inicial do meu aprendizado em JavaScript. Os códigos foram mantidos como exercícios de prática e podem conter soluções simples e pontos de melhoria.
